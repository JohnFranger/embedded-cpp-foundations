# Lesson 36 - Tilt Switches

## Circuit Concept

- **Goal:** Learn to use a tilt switch.
- **Components:** 2× LED, 1× current-limiting resistor (≈220 Ω), jumper wires, tilt switch.
- **Wiring:** Pin 5,13 → resistor → LED anode; LED cathode → GND.
              Pin 2 -> Tilt Switch -> GND


## Mathematical or Physical Proof / Analysis

- **Tilt Switch:**
  There's a ball on the inside that will close the circuit when it is not tilted or open
  it when it is.
