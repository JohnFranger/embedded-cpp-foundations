# Lesson 18 — Reading from Serial Monitor

## Circuit Concept

- **Goal:** Use Serial.ParseInt/ParseFloat to gather information like number of blinks. 
- **Components:** 1× LED, 1× current-limiting resistor (≈330 Ω), jumper wires.
- **Wiring:** Pin 5 → resistor → LED anode; LED cathode → GND.

```
D5 ──[ 220Ω ]──▶|── GND
                LED
```
