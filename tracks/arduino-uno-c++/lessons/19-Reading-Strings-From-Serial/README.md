# Lesson 19 - Reading Strings From Serial

## Circuit Concept


- **Goal:** Read user choice to select a LED to turn on. 
- **Components:** 3× LED, 3× current-limiting resistor (≈330 Ω), jumper wires.
- **Wiring:** Pin 2,5,11 → resistor → LED anode; LED cathode → GND.

```
2,5,11 ──[ 330Ω ]──▶|── GND
                  LED
```
