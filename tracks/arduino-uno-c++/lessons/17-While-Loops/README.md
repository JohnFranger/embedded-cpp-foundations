# Lesson 17 - While Loops

## Circuit Concept

- **Goal:** Use a while loop and potentiometer to determine if a LED comes on. 
- **Components:** 1× LED, 1× current-limiting resistor (≈330 Ω), jumper wires, 1x Potentiometer.
- **Wiring:** Pin 5 → resistor → LED anode; LED cathode → GND.
              5V → Potentiometer | A5 → GND

```
Pin 5 ──[ 330Ω ]──▶|── GND
                  LED
5V ──[ Potentiometer ]─ GND
           A5
```
