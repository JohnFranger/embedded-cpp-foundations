# Lesson 04 — Understanding Variables

## Circuit Concept

- **Goal:** Use variables to cut down on repetitive code.
- **Components:** 1× LED, 1× current-limiting resistor (≈330 Ω), jumper wires.
- **Wiring:** Pin 4 → resistor → LED anode; LED cathode → GND.

```
4 ──[ 220Ω ]──▶|── GND
                LED
```

## Mathematical Proof / Analysis

- **Current limiting (Ohm's law)**
- **Blinking on a delay:**
  Delay is in terms of miliseconds so delay/1000 = seconds.
