# Lesson 22 -- Active Buzzer

## Circuit Concept

- **Goal:** Use an active buzzer with a potentiometer to activate a buzzer
- **Components:** 1× Active Buzzer, jumper wires, potentiometer.
- **Wiring:** Pin 11 → Buzzer anode; Buzzer cathode → GND.
              5V → Potentiometer; A3 → GND 
              ```
Pin 11 ── Buzzer ── GND
5V ── Potentiometer/ A3 ── GND            
```
