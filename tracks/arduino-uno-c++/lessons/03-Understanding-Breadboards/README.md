# Lesson 03 — Understanding The Breadboard

## Circuit Concept


- **Goal:** Understanding the breadboard and how it connects.
- **Components:** 1× LED, 1× current-limiting resistor (≈330 Ω), jumper wires.
- **Wiring:** Pin 13 → resistor → LED anode; LED cathode → GND.

```
13 ──[ 220Ω ]──▶|── GND
                LED
```

## Mathematical Proof / Analysis

- **Current limiting (Ohm's law)**
- **Blinking on a delay:**
  Delay is in terms of miliseconds so delay/1000 = seconds.
