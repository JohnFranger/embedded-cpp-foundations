# Lesson 08 - Pulse Width Modulation

## Mathematical Proof / Analysis

- **How PWM works:** Instead of simply passing a voltage between 0V and 5V, PWM passes rapidly changing on and off signals (HIGH and LOW; 5V and 0V).
- **Oscilliscopes:** By using an osciliscope (a tool to vizualize voltage) you can regonize the approximate period and seeing that the "high" and "low" voltages 
  represent a fraction corresponding to an average voltage.
- **Capacitors:** By using a capacitor, one can smooth out the line so that it looks like a constant average voltage.
