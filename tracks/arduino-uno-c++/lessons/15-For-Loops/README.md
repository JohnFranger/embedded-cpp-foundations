# Lesson 15 - For Loops

## Circuit Concept

- **Goal:** Blink one light 3 times, and the other 5 times using for loops.
- **Components:** 1× LED, 1× current-limiting resistor (≈330 Ω), jumper wires.
- **Wiring:** Pin 9 → resistor → LED anode; LED cathode → GND.
              Pin 6 → resistor → LED anode; LED cathode → GND.

```
Pin 6 ──[ 330Ω ]──▶|── GND
                   LED
Pin 9  ──[ 330Ω ]──▶|── GND
                   LED
```
