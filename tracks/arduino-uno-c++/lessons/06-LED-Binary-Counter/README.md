# Lesson 06-LED-Binary-Counter

## Circuit Concept

- **Goal:** Count in binary using 4 LEDs.
- **Components:** 4× LED, 4× current-limiting resistor (≈330 Ω), jumper wires.
- **Wiring:** Pin 2,3,4,5 → LED anode; LED cathode → resistor → GND.

```
2,3,4,5 ──▶|── [ 330Ω ] ── GND
        LED
```
